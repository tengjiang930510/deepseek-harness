Desktop 移动访问与手机浏览器（H5）自动连接 PRD

版本 mobile-access-enterprise-v1 · 2026-11-12 · 第 3 轮 · 学 Codex Remote · 钉死一机 · 无单独原型

结论：体验对齐 ChatGPT Codex Remote（电脑开远程出码 → 手机扫码/链接绑主机 → 电脑管设备）；通道用现网 dsh-mobile + FRP；客户端为浏览器/H5。一人一机钉死，不做最近登录漂移；设备名=企业用户；配对免手填名称。不另做原型。

职能泳道：flow_core_swimlane.html · 全文：prd.md

目标与非目标

类型内容
目标Desktop 开关 + 企业 FRP；浏览器/H5 自动连；跟随电脑登录；WebView 可复用
非目标本版原生 App；无绑定裸奔；手机独立企业写会话

需求与优先级

优先级需求验收
P0Desktop「移动访问」默认关；开→就绪；关→公网不可用
P0企业预置通道安装包内嵌配置
P0浏览器远程配对配对链接完成首次绑定
P0日常免扫同浏览器再开 Origin 自动连
P0学 Codex 绑主机扫码/链接钉死当前 Desktop；无多机点选、无漂移
P0设备名=用户绑定电脑设备列表按企业用户管理/撤销
P0跟随电脑登录登录后自动进壳
P0分步等待态通道/绑定/登录文案互斥
P1主屏幕指引交付说明含添加步骤
P1H5 嵌 App 预留WebView 可加载同一 Origin
P2企业 App 容器后续版本

主流程

  1. Desktop 登录并打开「移动访问」至就绪。
  2. 复制远程配对链接 → 手机浏览器打开完成首次绑定。
  3. 建议添加到主屏幕或收藏。
  4. 之后打开入口自动连；电脑未登录则等待，登录后进入简易壳。

阶段文案

阶段文案
need_bind请使用电脑提供的配对链接完成首次绑定
tunnel_off请在电脑打开「移动访问」后再试
waiting_pc_login请先在电脑完成登录；登录并选择项目后将自动进入
waiting_pc_creds电脑尚未就绪模型凭据，请在电脑重新登录后再试
entering正在进入助手…

场景

正常

通道开、已配对、电脑已登录 → 浏览器打开即进壳（可经短暂检测）。

边界

情况行为
未开移动访问tunnel_off
未登录waiting_pc_login，登录后自动进
清缓存/换浏览器重新配对
未来 App WebView加载同一 H5；Cookie 策略 P2 验收

异常

异常兜底
配对过期电脑重新生成链接
设备撤销提示失效并重配
证书过期运维续期

风险

风险缓解
找不到入口固定 Origin + 主屏幕指引
清缓存掉绑定失效文案 + 重配说明
误以为必须装 App交付写明浏览器即可

验收要点

#步骤期望
1默认开关关
2打开开关discovery=200
3浏览器配对链接首次绑定成功
4同浏览器再开免扫自动连
5电脑退出登录等待后可自愈进入
6关移动访问通道未开文案

待确认

客户端已定为浏览器/H5。请业务在上线前给出正式 Origin（固定 IP 或域名）。企业 App 容器名称与排期作 P2 即可。
