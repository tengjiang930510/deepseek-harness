手机同看简易壳（仿 Go）PRD

版本 mobile-go-shell-v1 · 2026-11-05 · 分支 feat/t4y-mobile-cowatch

结论：手机 UA 下将同源 Web 收成仿 Go 简易对话壳——右上角模型、输入框上方企业胶囊条、左滑快捷；仅改 t4y-mobile-cowatch，桌面零激活。

需求与优先级

优先级需求验收
P0简易对话框消息区 + 圆角输入；侧栏/右栏隐藏
P0模型右上角顶栏右侧可切换模型
P0胶囊条Hub 快捷在输入框上方横向滑动
P0桌面零误伤桌面 UA 不激活
P1左滑快捷插件 / 设置 / 会话入口

对标 Go 与差异

项Go 手机本需求
模型点进输入后在输入框下方顶栏右上固定
企业快捷无输入框上方胶囊
左滑有要做

场景

正常

电脑已登录 → 手机进同源 Web → WaitGate 消失 → 简易壳：选模型、点胶囊、发消息、左滑进设置/插件。

边界

无快捷则胶囊不占位；有草稿则胶囊禁用；仅右缘起滑打开面板。

异常

未登录保持 WaitGate；手势与内容横滑隔离。

实现边界

只改 t4y-mobile-cowatch。Hub 桌面座位不变，手机壳用 CSS/壳层消费既有 .t4y-shortcut-bar。

风险

风险缓解
哈希类名data-* / class*= 选择器
模型挪位失焦视觉定位保留原 trigger
左滑误触右缘手势 + 遮罩关闭
