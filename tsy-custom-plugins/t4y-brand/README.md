# t4y-brand

Replaces the Web client fish mark with the CRCC mark and shows **铁四院智能助手** in the sidebar. The conversation hero headline is set in `@deepseek-ai/dsh-client-ui-conversation` locales.

## Install

```sh
pnpm dsh plugin --profile web add ./tsy-custom-plugins/t4y-brand
```

Restart `pnpm dsh web`.

## Assets

- `assets/crcc-mark.png` — resized logo embedded into `client.js`
- Source: `crcc-mark-v2-transparent.png`
