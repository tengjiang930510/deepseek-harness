# t4y-capability-hub

[English](README.md) | 中文

职责、调用流程、状态和边界见 [企业插件实现与边界](../PLUGIN-REFERENCE.md#t4y-capability-hub)。

开发流程见 [DEVELOPING.md](./DEVELOPING.md)。

负责设置 → **授权插件** 页面、快捷按钮和分组命令候选。它请求 Host 读取已登录用户当前项目菜单，再从可见表单叶子读取 `插件名`、`项目名`、`插件种类` 和 `插件图标` 记录。每条记录分别解析 Gitee `latest.json`；发布管理器从普通插件列表过滤企业管理的包。

Host 安装前再次查询菜单和表单，因此修改浏览器状态或直接调用本地安装接口不能获得企业系统未返回的插件。用户可见文案位于 [`client.js`](./client.js) 的 `hubCopy`。

对于记录 `{ "name": "oa-helper", "projectName": "wuhanmetro" }`，Host 从 Gitee Hub 读取 `wuhanmetro/plugins/oa-helper/latest.json`。该文件提供包名、不可变提交和源码坐标及当前版本。界面只安装或更新到当前版本。

## 安装

```sh
pnpm dsh plugin --profile web add ./tsy-custom-plugins/t4y-capability-hub
```

重新启动 `pnpm dsh web`。

授权插件按表单中的“插件种类”分组；未填写时使用企业菜单中的上级目录。插件图标使用表单中上传的第一张图片，图片不可用时显示默认图标。在插件卡片勾选“在输入框显示快捷按钮”后，已安装并启用的插件命令会出现在会话输入框工具行。点击按钮与从斜杠菜单选择命令一样，会插入蓝色命令标记，需用户自行确认发送；输入框已有内容或附件时按钮不可用。选择保存在当前浏览器中，按企业、账号和项目隔离。切换项目或登录状态时会重新查询授权。手机同看场景下的座位由 `t4y-mobile-cowatch` 另行排布。

输入 `/` 时，已启用插件的命令按表单“插件种类”分组，标题显示匹配的插件数量；每项使用表单上传的图标。

插件使用输入候选来源与菜单槽位展示分类，在展示层合并同名的系统命令并复用 DSH 菜单组件；命令解析和执行继续由 DSH 完成。该适配依赖 DSH 菜单槽位和输入控制器，升级 DSH 时应复验 `/`、`@`、鼠标、键盘与窄窗口行为。

快捷按钮和 `/` 菜单先查询当前企业、账号和项目的授权；同一页面内复用查询结果。刷新页面、重新登录、切换项目或通过授权插件页修改插件状态时重新查询；查询失败时不展示旧授权。企业系统没有变更推送时，页面无法立刻获知管理员在后台收回的权限。

浏览器持久存储只缓存插件名称、图标地址、版本、包名、命令和描述等资料；授权结果只保存在当前页面内存中，不跨页面刷新或账号、项目复用。已缓存的资料仅与当前授权返回的插件匹配；缺少资料或安装版本变化时重新读取发布信息。
